# Определение дороги в карьере

Компактный проект решает задачу в два этапа:

1. `RoadNet` (DeepLabV3/ResNet-50) сегментирует всю проезжаемую поверхность. Отверстия в маске остаются препятствиями.
2. Динамическое программирование находит устойчивый основной путь через широкие и уверенные области маски. На развилке путь выбирается по направлению машины и предыдущему кадру. Левая, центральная и правая зоны строятся вдоль этого пути, а боковые ветви не растягивают центральную зону.

## Установка

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Подготовка приложенного датасета

Частичная проверка только на первой поездке (`trip01`, 48 равномерно выбранных кадров):

```powershell
.venv\Scripts\python prepare_data.py "C:\Users\quwwi47\Downloads\Telegram Desktop\data.zip" --trip trip01 --limit 48
```

Пустые маски сохраняются как корректные примеры «дороги нет». Чтобы извлечь весь `trip01`, укажите `--limit 0`.

## Разметка

```powershell
.venv\Scripts\python label.py dataset\trip01\images dataset\trip01\masks
```

Левая кнопка рисует дорогу, правая стирает. `B` — кисть, `P` — полигон, `Enter` — залить полигон, `Z` — отмена, `S` — сохранить, `N/A` — следующий/предыдущий кадр, `+/-` — размер кисти.

Размечайте всю видимую проезжаемую поверхность. Препятствия оставляйте чёрными. Не рисуйте три зоны вручную: они вычисляются из геометрии и истории кадров.

## Обучение

```powershell
.venv\Scripts\python train.py dataset\trip01 --epochs 30 --batch 4
```

В консоли печатаются `train_loss`, `val_loss`, `IoU`, `Dice`, точность на пустых кадрах `no_road_acc` и время эпохи. Разделение хронологическое 80/20, поэтому соседние почти одинаковые кадры не попадают одновременно в обучение и проверку.

## Инференс и статистика

```powershell
.venv\Scripts\python infer.py VIDEO.mp4 runs\roadnet.pt --out runs\video_result
```

Для каждого кадра печатаются площадь дороги, доли трёх зон, направление, уверенность и FPS. Цвета: синий — левая, зелёный — центральная, красный — правая. Чёрные разрывы остаются препятствиями.
