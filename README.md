# Определение дороги в карьере

Компактный проект решает задачу в два этапа:

1. `RoadNet` в режиме `fast` (LR-ASPP/MobileNetV3, 320×180) сегментирует проезжаемую поверхность на слабом CPU. Режим `accurate` оставляет DeepLabV3/ResNet-50 с разрешением 512×288. Отверстия в маске остаются препятствиями.
2. Медиальный скелет строится для всей дорожной сети. Каждая ветвь получает собственную локальную ось, направление и ширину, поэтому левая, центральная и правая зоны продолжаются после развилок и слияний. Препятствия остаются отверстиями в зонах.

## Установка

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Общее меню

Запустите `start.bat` двойным щелчком или выполните:

```powershell
.venv\Scripts\python main.py
```

Из одного меню доступны подготовка датасета, разметка, обучение, инференс и проверка геометрии.

## Подготовка приложенного датасета

Частичная проверка только на первой поездке (`trip01`, 48 равномерно выбранных кадров):

```powershell
.venv\Scripts\python prepare_data.py "C:\Users\quwwi47\Downloads\Telegram Desktop\data.zip" --trip trip01 --limit 48
```

Пустые маски сохраняются как корректные примеры «дороги нет». Чтобы извлечь весь `trip01`, укажите `--limit 0`.

## Разметка

```powershell
.venv\Scripts\python label.py dataset\trip01\images dataset\trip01\masks
```

Левая кнопка рисует дорогу, правая стирает. `B` — кисть, `P` — полигон, `Enter` — залить полигон, `Z` — отмена, `S` — сохранить, `N/A` — следующий/предыдущий кадр, `+/-` — размер кисти.

Размечайте всю видимую проезжаемую поверхность. Препятствия оставляйте чёрными. Не рисуйте три зоны вручную: они вычисляются из геометрии и истории кадров.

## Обучение

```powershell
.venv\Scripts\python train.py dataset\trip01 --epochs 30 --batch 4 --arch fast
```

Во время каждого обучающего и проверочного батча отображаются полоса выполнения, проценты, loss, прошедшее время и ETA. После эпохи печатаются `train_loss`, `val_loss`, `IoU`, `Dice`, точность на пустых кадрах `no_road_acc` и общее время. Разделение хронологическое 80/20, поэтому соседние почти одинаковые кадры не попадают одновременно в обучение и проверку.

## Инференс и статистика

```powershell
.venv\Scripts\python infer.py VIDEO.mp4 runs\roadnet.pt --width 256 --output-video runs/result.mp4
```

Для каждого кадра печатаются площадь дороги, доли трёх зон, направление, уверенность и FPS. Цвета: синий — левая, зелёный — центральная, красный — правая. Чёрные разрывы остаются препятствиями.

Во время обработки открывается live-окно с размеченными кадрами и показателями FPS, направления и уверенности. `Q`/`Esc` — остановка, `Space` — пауза. Для запуска без окна добавьте `--no-show`. Ширина `256` предназначена для слабого CPU, `320` даёт более точные границы.

Результат записывается сразу в один MP4 без промежуточных JPEG. Разрешение и частота кадров берутся из исходного видео. Параметр `--output-video` можно не указывать, если нужен только live-просмотр.
